SISTEM PENJUALAN - Praktikum Modul 08 (Session dan Security)

Cara pakai (XAMPP/Laragon):
1. Salin folder "penjualan" ke htdocs.
2. Import penjualan.sql lewat phpMyAdmin (database "penjualan" dibuat otomatis).
3. Sesuaikan koneksi.php bila user/password MySQL berbeda.
4. Buka http://localhost/penjualan/

Akun uji:
- Owner (level 1) : owner / owner123
- Kasir (level 2) : kasir / kasir123
